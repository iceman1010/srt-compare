This project is a TUI app that is able to compare 2 different subtitles on screen, line by line, caption by caption, when you scroll down down or up. 

the name of the app / command: srt-compare

Command parameters:

srt-compare -i subtitle-1.srt -i subtitle-2.srt

The app should be written in PHP, and at the end, it should be a self-contained PHAR file. To parse subtitles, please use the package "mantas-done/subtitles" (search for it). Best would be if you install any dependency via composer
